## 视频合集目的

本视频合集面向正在求职的同学，希望和大家一起刷完 [LeetCode hot 150](https://leetcode.cn/studyplan/top-interview-150/)。

内容特别强调将**算法题思路**与**编码实现**分开：视频中重点讲解解题思路，再使用 Agent 完成题目的编码实现。
